# 🎉 Interactive Birthday Celebration Website

An elegant, interactive, and fully responsive birthday celebration website built using **HTML, CSS, and JavaScript**. Designed to create a memorable digital birthday experience with immersive animations, personalized surprises, and engaging interactive features.

---

## ✨ Features

* 🎂 Live Birthday Countdown
* 🔒 Interactive Lock Screen
* 🎈 Balloon Pop Challenge
* 🎉 Confetti & Celebration Effects
* 🌌 Floating Particles and Animated Background
* 🖼️ Responsive Photo Gallery
* 🎵 Background Music Player
* 💌 Digital Wish Wall
* 🧩 Fun Birthday Quiz
* 🎁 Surprise Unlock Section
* 🌙 Light/Dark Theme Toggle
* 📱 Fully Responsive Design
* ⚡ Smooth Animations & Performance Optimizations

---

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript (ES6)

## 🚀 Getting Started

1. Clone the repository.

```bash
git clone https://github.com/your-username/birthday-website.git
```

2. Open the project folder.

```bash
cd birthday-website
```

3. Launch the project by opening `index.html` in your browser.

No additional dependencies or installation are required.
